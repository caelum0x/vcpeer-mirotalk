## APIs

All JSON unless noted. Base `/api/v1` unless noted. Auth kinds: `none`, `host` (API key or host-session via `ServerApi`/`hostProtection`), `rate-limited` (IP-based, stacked with the above).

### Core MiroTalk (app/src/server.js)
- `GET /docs` → Swagger UI. none.
- `GET /stats` → `{ rooms, peers, ... }`. host.
- `POST /token` → `{ token }` (JWT for presenter/peer). host.
- `GET /meetings` → `[{ roomId, ... }]`. host.
- `POST /meeting` → `{ meeting: url }`. host.
- `POST /join` → `{ join: url }`. host.
- `GET /activeRooms` → `[{ roomId, peers }]`. none, gated by `config.ui.rooms.showActive`.
- `POST /isRoomActive`, `POST /isWidgetRoomActive` (non-versioned) → `{ msg: bool }`. none.
- `GET /createRoomToken` (non-versioned) → `{ token }`. rate-limited.
- `GET /oidcIdentity` (non-versioned) → `{ ... }` or 401. OIDC session.
- `POST /login` (non-versioned) → sets session cookie / redirect. rate-limited.
- `POST /slack` (non-versioned, slash-command) → `{ text: meetingUrl }`. Slack signing-secret verified.
- `GET /buttons`, `GET /themes`, `GET /brand` (non-versioned) → static config JSON. none.

### Send (app/src/server.js + app/src/transfers/transferRoutes.js)
- `POST /send/code` → mint 6-digit code aliasing a `send-*` room token. body `{ channel }`. rate-limited (`sendCodeLimiter`), rejects non-`send-` channels.
- `GET /send/code/:code` → `{ channel }` or 404/400. rate-limited (`sendCodeResolveLimiter`).
- Mounted at `/transfers` ("Send a link" — server-stored, encrypted at rest):
  - `GET /config` → `{ chunkBytes, maxTransferBytes, defaultExpiryDays, allowedExpiryDays, previewMaxBytes, maxRecipients }`. none.
  - `POST /` → create transfer. body `{ files[], delivery, message, expiryDays, maxDownloads, recipients, senderEmail }`. rate-limited, XSS-checked.
  - `GET /:id/files/:fileId/status` → `{ uploadedParts[], totalChunks }`. none (id is the secret).
  - `PUT /:id/files/:fileId/chunks/:partNumber` → raw body upload, ≤ `chunkBytes+1MB`. rate-limited.
  - `POST /:id/verify-email/request` / `/confirm` → email-gated recipients. rate-limited.
  - `POST /:id/finalize` → assembles parts, marks `ready`.
  - `GET /:id` → public metadata once `ready`.
  - `GET /:id/files/:fileId/preview` → inline stream for previewable types ≤ `previewMaxBytes`.
  - `GET /:id/files/:fileId/download`, `GET /:id/zip` → gated by download-count via `gateDownload`.
  - `GET /manage/:manageToken` / `DELETE /manage/:manageToken` → sender-side status/delete.
  - `POST /:id/report` → abuse report, body `{ reason }`.

### Clips (app/src/clips/clipRoutes.js, mounted `/clips`)
- `GET /config`, `POST /` (create), `GET /:id/status`, `PUT /:id` (chunk upload), `POST /:id/finalize`, `GET /:id` (metadata), `POST /:id/view` (counter++), `GET /:id/video` (stream), `GET /manage/:manageToken`, `DELETE /manage/:manageToken`. Same shape family as transfers; storage via `LocalDiskStorage`/`R2Storage`.

### Coworker (app/src/coworker/coworkerRoutes.js, mounted `/coworker`)
- `POST /message` → `{ threadId, text }` → OpenAI-backed reply, rate-limited.
- `GET /thread/:threadId` → persisted exchange history.
- `POST /slack/events` → Slack Events API bridge, rate-limited, signature-verified.

### Launchboard / Notify (non-versioned + `/api/v1`)
- `GET /launchboard`, `POST /launchboard/submit` (rate-limited, atomic JSON write), `GET /api/v1/launchboard/listings`.
- `GET /notify`, `POST /notify/submit` (rate-limited, atomic JSON write).

### Socket.IO (real-time, app/src/server.js ~1660-2960)
Events: `join`, `relayICE`, `relaySDP`, `roomAction`, `peerName`, `message`, `cmd`, `peerStatus`, `peerAction`, `caption`, `getWhisperTranscription`, `kickOut`, `fileInfo`, `fileAbort`, `fileReceiveAbort`, `videoPlayer`, `wbCanvasToJson`, `whiteboardObject`, `whiteboardPointer`, `whiteboardAction`, `videoDrawing`, `disconnect`, `data` (sub-dispatch incl. `checkPeerName`, `getChatGPT` → OpenAI proxy, scoped to joined peers, 20-message context cap, retried on 5xx).

Note: `app/api/{join,meeting,meetings,stats,token}/*.{js,php,py,sh}` are static example client snippets for the Swagger docs, not live endpoints.
