        Frequently asked questions

        How big can the files be?

        There's no size limit enforced by VCPeer. Files go straight from one browser to the other over a peer-to-peer connection, not through an upload server, so the practical limit is your device's storage and both browsers staying open for the duration of the transfer.

        Is it private?

        Yes. The file data is never uploaded to or stored on our servers — it streams directly between the sender's and receiver's browsers over an encrypted WebRTC data channel. Our server only helps the two browsers find each other (the same signaling VCPeer already uses for video calls).

        Does the receiver need an account?

        No. Opening the link or entering the 6-digit code is all that's required.

        What happens if I close the tab?

        Both the sender's and receiver's tabs need to stay open for the transfer to complete — there's no server in the middle to resume from. If the sender closes their tab, the link expires.
