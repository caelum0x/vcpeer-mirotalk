Looking for a self-hosted Zoom alternative? Run your own in minutes.

VCPeer is open source, AGPL-3.0. Copy the Docker Compose template, pull the image, and docker-compose up — your own video calling server is running, on your own infrastructure, with nobody else's usage limits or per-seat pricing. 

git clone https://github.com/caelum0x/vcpeer-mirotalk.git
cd vcpeer-mirotalk
cp docker-compose.template.yml docker-compose.yml
docker-compose pull
docker-compose up -d

That is the whole install. The image is on Docker Hub, and the full self-hosting guide covers TURN servers, HTTPS, and production tuning for when you move past a single box.

Not every team wants to run their own server. If you just want to start a call right now, VCPeer also runs a free hosted instance — same code, nothing to deploy.
