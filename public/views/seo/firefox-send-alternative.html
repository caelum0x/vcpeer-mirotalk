Looking for a Firefox Send alternative? Here's one that's still running.

Mozilla shut Firefox Send down in 2020. VCPeer Send does the same job — drop a file, get a link, the other person opens it and downloads it — with no account and no size limit enforced by VCPeer.

The difference: Firefox Send stored an encrypted copy on Mozilla's servers until it expired or was downloaded. VCPeer Send never stores the file anywhere — it streams peer-to-peer, directly from your browser to theirs, with a SHA-256 check so you both know it arrived intact.

That means both browser tabs need to stay open until the transfer finishes. In exchange, there is no copy sitting on a server for anyone to request, lose, or leave exposed after the link expires.
