Looking for a WeTransfer alternative? Send large files free.

Drop a file, get a link, QR code, or 6-digit code — the other person opens it and the file streams straight to their browser. No account, no upload step, and no size limit enforced by VCPeer.

Unlike an upload-then-download service, the file never sits on a server in between: it moves over an encrypted peer-to-peer connection directly from your browser to theirs, with a SHA-256 check so you both know it arrived intact.

Both browser tabs need to stay open until the transfer finishes — that's the trade-off for files never touching our servers.
